# LBL Store - MVP (Experiência Prática I)

Sistema desenvolvido para automatizar e centralizar a gestão de inventário, catálogo e pré-encomendas (*pre-orders*) da **LBL Store**, eliminando os gargalos operacionais de controle via chat.

## 🚀 Funcionalidades do MVP
- **Dashboard:** KPIs em tempo real, alertas visuais de prazos críticos de lotes internacionais e resumo de pedidos.
- **Catálogo:** Tabela filtrável de colecionáveis com controle de estoque e status automatizados.
- **Pré-orders:** Gestão de lotes de importação (AmiAmi, Solaris, Good Smile US) com barras de progresso e prazos em destaque.
- **Pedidos:** Acompanhamento de status e fluxo de atendimento aos compradores.

## 🛠️ Tecnologias Utilizadas
- **Backend:** Node.js com Express
- **Frontend:** HTML5, JavaScript e Tailwind CSS
- **Arquitetura:** Aplicação leve focada em usabilidade e facilidade de execução local.
